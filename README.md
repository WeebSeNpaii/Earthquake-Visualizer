# Earthquake-Visualizer
Earthquake visualizer is a 'MERN Stack' project which allows users to visualize recent earthquakes and seismic patterns all over the world.

## Features

- Display recent earthquakes on an interactive world map using **Leaflet.js**.
- Filter earthquakes by magnitude, location.
- Search and select specific earthquake events from a dropdown list.
- Zoom into selected earthquake location for better visualization.
- Automatic updates using a cron job for real-time earthquake data.
- Mobile-friendly and responsive design.

---

## Tech Stack

- **Frontend:** React.js, Leaflet.js, Tailwind CSS  
- **Backend:** Node.js, Express.js  
- **Database:** MongoDB  
- **Others:** Axios, Cron, JWT Authentication
